직원·경찰이 하는 질문 4개

질문 바로 아래에 대답을 붙였어요. 스피커를 누르면 원어민 발음, 한 번 더 누르면 느린 속도로 들려요.

  • Q1What seems to be the problem?무슨 문제가 있으세요?실제로 들리는 소리왓 씸즈터비 더 프라블럼?to be가 '터비'로 약하게 붙어요.
    이렇게 대답해요
    I lost my wallet.지갑을 잃어버렸어요.이렇게 바꿔 말해도 돼요my phone폰my passport여권
    I don't feel well.몸이 안 좋아요.이렇게 바꿔 말해도 돼요Is there a pharmacy nearby?근처에 약국 있어요?
  • Q2When did you last see it?마지막으로 본 게 언제예요?실제로 들리는 소리웬디쥬 래스씨잇?did you가 '디쥬'로 붙고, last의 t가 빠져 '래스'처럼 들려요.
    이렇게 대답해요
    I think I left it in the taxi.택시에 두고 내린 것 같아요.이렇게 바꿔 말해도 돼요on the bus버스에at the café카페에
  • Q3Your flight has been canceled.항공편이 결항됐어요.실제로 들리는 소리유어 플라잇 해즈빈 캔슬드has been이 '해즈빈'으로 짧게 붙어요. delayed(지연)도 자주 들려요.
    이렇게 대답해요
    Can you put me on the next flight?다음 항공편으로 바꿔 주실 수 있어요?
  • Q4Do you have travel insurance?여행자 보험 있으세요?실제로 들리는 소리듀해브 트래블 인슈어런스?Do you have가 '듀해브'로 뭉개져요. 병원이나 분실 신고에서 꼭 물어봐요.
    이렇게 대답해요
    Yes, I do.네, 있어요.
연상법 자음 세 개가 겹치면 가운데가 빠져요. last see → 래스씨, 'next flight'도 '넥스 플라잇'처럼 들려요.

내가 먼저 말할 때

직원이 묻기 전에 내가 먼저 부탁하거나 물어볼 때 쓰는 문장이에요.

  • 급할 때Please call an ambulance.구급차 좀 불러 주세요.
  • 먼저 말할 때I need a police report for my insurance.보험 때문에 경찰 확인서가 필요해요.

알아 두기 여권을 잃어버렸다면 가까운 한국 대사관이나 영사관에 바로 연락해요. 경찰 확인서가 있으면 여권 재발급과 보험 처리가 빨라져요.

실제로는 이렇게 흘러가요

  • Hi. What seems to be the problem?안녕하세요, 무슨 문제가 있으세요?
  • I lost my wallet.지갑을 잃어버렸어요.
  • When did you last see it?마지막으로 본 게 언제예요?
  • I think I left it in the taxi.택시에 두고 내린 것 같아요.
  • Do you have the receipt? We can call the taxi company.영수증 있으세요? 택시 회사에 연락해 볼게요.
  • Yes, here it is. Thank you so much.네, 여기요. 정말 감사해요.

택시 영수증에는 차량 번호나 회사 연락처가 있어요. 내릴 때 영수증을 받아 두면 이럴 때 도움이 돼요.

문장이 생각 안 날 때

  • I need help, please.도와주세요.

당황하면 아무 말도 안 떠오를 수 있어요. 이 한 문장으로 시작하면 상대가 질문으로 이끌어 줘요.

오늘의 표현, 직접 써 보기

오늘 배운 표현으로 나만의 문장 2개 만들기
정답과 연상법
  1. ① 마지막으로 본 게 언제예요? — When did you last see it?이 붙어서 들린 거예요. 물건을 마지막으로 본 때를 묻는 질문이에요.
    연상법 · last + see = 마지막으로 본 때
  2. ① I think I left it in the taxi. — leave의 과거형 left는 '두고 오다'예요. 물건을 어디에 두고 왔다고 할 땐 left를 써요.
    연상법 · left = 두고(leave) 왔다. 왼쪽(left)에 두고 내렸다!
  3. ① Can you put me on the next flight? — put me on ~은 '나를 ~에 태워 주다'예요. 결항·지연 때 카운터에서 바로 써요.
    연상법 · put me on = 나를 올려(put) 태워(on) 줘요

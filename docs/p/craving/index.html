뜻

I'm craving + 음식.~가 엄청 당겨, 너무 먹고 싶어

crave는 '간절히 원하다'라는 뜻이에요. I want pizza보다 훨씬 강하고 생생해서, 갑자기 특정 음식이 당길 때 원어민이 정말 자주 써요. 음식이 아닌 것에도 쓸 수 있어요.

연상법 크레이브(crave) → '크~ 땡긴다!'로 기억해 보세요.

예문

  • I'm craving pizza right now.지금 피자 너무 당겨.
  • I've been craving tteokbokki all day.하루 종일 떡볶이가 당겼어.
  • I have a craving for something sweet.단 게 당겨.

비슷한 표현

  • I could go for some coffee.커피 한잔하면 딱 좋겠다.
  • I'm in the mood for Mexican food.오늘은 멕시코 음식이 먹고 싶은 기분이야.

실제로는 이렇게 흘러가요

  • What do you want for dinner?저녁 뭐 먹고 싶어?
  • Honestly, I'm craving something spicy.솔직히 매운 게 당겨.
  • Same here. How about tteokbokki?나도. 떡볶이 어때?
  • Perfect. I've been craving it all week.딱 좋아. 일주일 내내 당겼거든.

알아 두기 craving은 음식 말고도 '간절히 원하는 것'에 써요. I'm craving some quiet time.(조용히 쉬고 싶어 죽겠어)처럼요. 다만 사람에게는 잘 쓰지 않으니 음식·휴식·경험에 쓰면 자연스러워요.

자주 하는 실수

  • I'm craving for pizza.I'm craving pizza.동사 crave는 for 없이 바로 음식을 붙이는 게 가장 자연스러워요.왜?crave는 want처럼 원하는 대상을 바로 받는 동사라서 I'm craving pizza라고 해요. (crave for도 쓰긴 하지만 덜 흔해요.)
  • I have a crave for chocolate.I have a craving for chocolate.have a 뒤에는 명사 craving이 와요.왜?crave(몹시 원하다)는 동사라서 a 뒤에 올 수 없어요. a 뒤에는 명사가 와야 하니 명사형 craving(갈망)을 써요.

정답과 연상법
  1. ② 라면이 너무 당겨 — I'm craving ~ = ~가 엄청 당겨, 너무 먹고 싶어.
    연상법 · 크레이브 → 크~ 땡긴다!
  2. ② craving — have a craving for ~ 형태로 써요. 동사로 쓰면 I'm craving chocolate.
    연상법 · have a + 명사(craving) + for!
  3. ② 커피 한잔하면 좋겠다 — I could go for ~ = ~가 있으면 딱 좋겠다, ~하고 싶다. 부드럽게 원하는 걸 말할 때 써요.
    연상법 · 커피를 향해(for) 갈(go) 수 있을 것 같아 = 땡겨!

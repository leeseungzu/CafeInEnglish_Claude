뜻

I'm running late.(가는 중인데) 좀 늦을 것 같아요 / 예정보다 늦어지고 있어요

약속 장소로 가는 길에 시간이 빠듯해졌을 때, 상대에게 미리 알리는 말이에요. 메리엄웹스터 사전은 run late를 '예상한 시각보다 늦게 도착하거나 떠나다'로 풀이하고, 예문으로 I have to hurry. I'm running late.(서둘러야 해. 늦겠어.)를 들어요. 옥스퍼드 학습자 사전에도 I'm running late for school.(학교에 늦겠어.)이 나와요.

핵심은 진행형이라는 점이에요. I'm late는 '나 늦었어'라는 상태라서 약속 시간이 이미 지났을 때 어울리고, I'm running late는 '지금 늦어지는 중'이라 아직 도착하기 전에 쓰기 좋아요. 그래서 원어민은 출발이 늦어졌거나 길이 막힐 때 이 문장으로 먼저 연락하고, 도착해서는 Sorry I'm late.라고 사과해요.

연상법 시계 바늘을 쫓아 뛰어가는(running) 모습. 열심히 뛰고 있지만 아직 늦는 중(late)이에요. 사실 여기서 run은 '달리다'보다 버스 시간표처럼 '진행되다'에 가까워서, 사람 말고 일정에도 쓸 수 있어요.

예문

  • Sorry, I'm running a little late.미안, 조금 늦을 것 같아.
  • I'm running about ten minutes late.10분쯤 늦을 것 같아요.
  • I'm running late for the meeting. Please start without me.회의에 늦을 것 같아요. 먼저 시작해 주세요.
  • The buses are running late because of the snow.눈 때문에 버스가 늦게 다니고 있어요.
  • Sorry to keep you waiting.기다리게 해서 죄송해요.

사람뿐 아니라 버스, 기차, 행사처럼 정해진 시간표가 있는 것에도 써요. 늦는 시간을 말하고 싶으면 running 뒤에 ten minutes처럼 넣으면 돼요.

  • No problem. Should we order first?괜찮아. 먼저 주문할까?
  • Yes, please. I'll be there in fifteen minutes.응, 그래 줘. 15분 뒤에 도착해.

'늦는다'를 동사로 생각하면 막혀요

한국어 '늦다'는 동사라서 '늦을 것 같아'를 그대로 옮기면 I will late.처럼 말하기 쉬워요. 하지만 영어 late는 '늦은, 늦게'라는 형용사·부사라 혼자서는 동사 노릇을 못 해요. 그래서 앞에 be나 run 같은 동사가 꼭 필요해요. I'll be late.(늦을 거야)도 맞는 말이고, 지금 가는 중이라는 느낌까지 담고 싶을 때 I'm running late.를 쓰면 돼요.

또 하나 조심할 단어가 lately예요. late에 -ly를 붙이면 '늦게'가 아니라 '최근에'라는 뜻이 돼요. I've been busy lately.는 '요즘 바빴어'라는 말이에요.

자주 묻는 질문

Q. 문자로 짧게 보내도 되나요?
네. 친구 사이 문자에서는 주어를 빼고 Running late, sorry!라고도 많이 보내요. 회사 메일이나 상사에게는 I'm running about 10 minutes late. Apologies for the delay.처럼 완전한 문장이 좋아요.

Q. the late는 무슨 뜻인가요?
사람 이름 앞에 붙은 the late는 '늦은'이 아니라 '고(故)'라는 뜻이에요. the late John Smith는 '고 존 스미스'예요. 뉴스에서 자주 보이니 같이 알아 두세요.

'15분 뒤에 도착해'처럼 시간을 말할 때 after가 아니라 in을 쓰는 이유는 in 10 minutes에서, 약속을 뜻하는 영어 단어는 '약속'을 영어로 말하는 3가지에서 확인해 보세요.

오늘 친구한테 "You're so nice!"라고 했다면, 700년 전 영국 사람은 깜짝 놀랐을 거예요. 그때 nice는 '멍청한'이라는 뜻이었거든요. 단어도 사람처럼 나이를 먹으면서 성격이 바뀌어요. 뜻이 거의 정반대로 바뀐 단어 5개를 모아 봤어요.

1. nice: 바보 → 친절한

nice의 뿌리는 라틴어 nescius, 글자 그대로 '모르는'이라는 뜻이에요. 온라인 어원 사전(Etymonline)에 따르면 이 말은 고대 프랑스어 nice를 거쳐 영어에 들어왔고, 13세기 후반 사람에게 쓸 때는 '어리석은, 무지한, 경박한'이라는 뜻이었어요. 그 뒤로 '까다로운', '세심한', '정확한' 같은 뜻을 거치다가, 1769년 무렵 '기분 좋은'이, 1830년 무렵 지금의 '친절한'이 기록돼요. 욕에서 칭찬까지 500년 넘게 걸린 셈이에요.

2. silly: 축복받은 → 웃기는

silly의 조상은 고대 영어 gesælig, '행복한, 운 좋은'이라는 뜻이었어요. 독일어 selig(축복받은, 행복한)와 같은 뿌리예요. Etymonline이 정리한 순서를 보면 '축복받은'에서 1200년 무렵 '순진한', 13세기 후반 '딱한', 1300년 무렵 '약한'으로 미끄러졌고, 1570년대에 '생각이 모자란, 어리석은'이 됐어요. 다만 지금은 stupid보다 훨씬 가벼운 말이라, 친한 사이에서 장난스럽게 많이 써요.

3. awful: 경외로운 → 끔찍한

awful은 글자 그대로 awe(경외감)에 -ful이 붙은 말이에요. 1300년 무렵에는 '존경하거나 두려워할 만한, 경외감을 일으키는'이라는 엄숙한 뜻이었어요. 그런데 Etymonline에 따르면 1809년쯤에는 뜻이 약해져 '아주 나쁜'으로 쓰였고, 1830년 무렵부터는 그냥 '몹시'를 뜻하는 강조어로도 쓰였어요. 재밌는 건 같은 awe에서 나온 awesome은 반대로 '끝내주는'이라는 칭찬이 됐다는 거예요. 형제 단어가 정반대 길을 간 셈이에요.

4. girl: 아이 → 여자아이

girl은 1300년 무렵 gyrle라는 모양으로 처음 기록되는데, 이때는 '아이, 젊은 사람'이라는 뜻으로 남녀 모두에게 썼어요. Etymonline에 따르면 여자아이에게 더 자주 쓰이긴 했고, 14세기 후반에 뜻이 좁아져 '여자아이'가 됐어요. 15세기 중반에는 '결혼하지 않은 젊은 여성'까지 가리키게 됐어요.

5. guy: 인형 이름 → 모든 사람

guy는 1605년 영국 의회를 폭파하려다 붙잡힌 가이 포크스(Guy Fawkes)의 이름에서 왔어요. 영국에서는 지금도 11월 5일 밤 그의 인형을 태우는 행사를 하는데, Etymonline에 따르면 1806년에 이 인형을 guy라고 부른 기록이 있어요. 1836년 영국에서는 '이상하게 차려입은 사람'이 됐고, 1847년 미국 영어에서 그냥 '남자, 녀석'이 됐어요. 지금은 'you guys'처럼 성별 상관없이 여러 사람을 부를 때도 써요.

뜻은 네 가지 방향으로 바뀐다

다섯 단어를 나란히 놓으면 뜻이 바뀌는 길이 보여요. 언어학에서는 이걸 크게 네 가지로 나눠요.

nice처럼 나쁜 뜻이 좋은 뜻이 되는 건 의미의 향상(amelioration), silly와 awful처럼 좋거나 중립인 뜻이 나빠지는 건 의미의 하락(pejoration)이라고 해요. girl처럼 가리키는 범위가 좁아지는 건 의미 축소(narrowing), guy처럼 한 사람의 이름이 모든 사람으로 넓어지는 건 의미 확대(broadening)예요.

  • nice: foolish → kind어리석은 → 친절한 (의미 향상)
  • silly: blessed → foolish축복받은 → 바보 같은 (의미 하락)
  • awful: awe-inspiring → very bad경외로운 → 끔찍한 (의미 하락)
  • girl: child → female child아이 → 여자아이 (의미 축소)
  • guy: Guy Fawkes effigy → man가이 포크스 인형 → 남자, 사람들 (의미 확대)

이 네 갈래를 알아 두면 낯선 단어의 옛 뜻을 만나도 덜 헷갈려요. 오래된 소설이나 시에서 silly나 nice를 만나면 지금 뜻으로 읽지 말고, 한 번쯤 사전의 옛 뜻을 확인해 보세요.

지금은 이렇게 써요

옛날 뜻은 잊어도 돼요. 대신 지금 쓰는 뉘앙스는 꼭 알아 두면 좋아요.

  • That's so nice of you.정말 친절하시네요. (고마울 때)
  • Don't be silly.무슨 소리야, 별말을 다 해. (상대가 미안해하거나 겸손할 때)
  • I feel awful about it.그거 정말 미안해. / 마음이 너무 안 좋아.
  • That's awesome!대박이다! 끝내준다!
  • Thanks, guys!다들 고마워! (남녀 섞인 모임에도 써요)

자주 하는 실수

  • 친구가 "도와줘서 고마워, 귀찮게 해서 미안해"라고 할 때You're silly.Don't be silly!무슨 소리야, 별거 아니야!왜?You're silly는 '너 참 엉뚱하다'처럼 사람을 평가하는 말이 돼요. Don't be silly는 '별말을 다 한다, 신경 쓰지 마'라는 따뜻한 관용 표현이에요.
  • 맛있는 음식을 먹고 감탄할 때This is awful good!This is awesome!이거 진짜 맛있다!왜?awful은 1830년 무렵부터 '몹시'라는 강조어로도 쓰였지만, awful good 같은 말은 지금 일부 구어에만 남아 낯설게 들릴 수 있어요. awful 하나만 쓰면 '끔찍하다'예요. 칭찬은 awesome, amazing이 확실해요.

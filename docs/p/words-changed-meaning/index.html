오늘 친구한테 "You're so nice!"라고 했다면, 700년 전 영국 사람은 깜짝 놀랐을 거예요. 그때 nice는 '멍청한'이라는 뜻이었거든요. 단어도 사람처럼 나이를 먹으면서 성격이 바뀌어요. 뜻이 거의 정반대로 바뀐 단어 5개를 모아 봤어요.

1. nice: 바보 → 친절한

nice의 뿌리는 라틴어 nescius, '모르는'이라는 뜻이에요. 이 말이 프랑스어를 거쳐 영어로 들어올 때는 '어리석은, 무지한'이라는 뜻이었어요. 그 뒤로 '까다로운', '세심한', '정확한' 같은 뜻을 차례로 거치다가, 18세기쯤 지금의 '좋은, 친절한'이 됐어요. 욕에서 칭찬까지, 수백 년에 걸친 대변신이에요.

2. silly: 축복받은 → 웃기는

silly는 고대 영어에서 '행복한, 축복받은'이라는 뜻이었어요. 독일어의 selig(축복받은)와 같은 뿌리예요. 그런데 '축복받은 → 순진한 → 딱한 → 약한 → 어리숙한' 순서로 뜻이 조금씩 미끄러지면서, 지금은 '바보 같은, 유치한'이 됐어요. 다만 stupid보다 훨씬 귀엽고 가벼운 말이라, 친한 사이에서 장난스럽게 많이 써요.

3. awful: 경외로운 → 끔찍한

awful은 글자 그대로 awe(경외감) + full, '경외감이 가득한'이라는 뜻이었어요. 신의 위엄 앞에서 쓰던 엄숙한 말이었죠. 그런데 '두려울 만큼 대단한'이 점점 '두려운'으로, 다시 그냥 '끔찍한, 형편없는'으로 바뀌었어요. 재밌는 건 같은 awe에서 나온 awesome은 반대로 '끝내주는'이라는 칭찬이 됐다는 거예요. 형제 단어가 정반대 길을 간 셈이에요.

4. girl: 아이 → 여자아이

중세 영어에서 girl(gurle)은 남자아이, 여자아이 구분 없이 '어린아이'를 가리켰어요. 남자아이는 'knave girl'처럼 앞에 말을 붙여 구분했을 정도예요. 시간이 지나면서 뜻이 좁아져 지금처럼 '여자아이'만 뜻하게 됐어요.

5. guy: 인형 이름 → 모든 사람

guy는 1605년 영국 의회를 폭파하려다 붙잡힌 가이 포크스(Guy Fawkes)의 이름에서 왔어요. 영국에서는 지금도 11월 5일 밤 그의 인형을 태우는 행사를 하는데, 이 인형을 'guy'라고 불렀어요. 그러다 '이상하게 차려입은 사람'이 됐고, 미국으로 건너가 그냥 '남자, 녀석'이 됐어요. 지금은 'you guys'처럼 성별 상관없이 여러 사람을 부를 때도 써요.

  • nice → foolish옛날 뜻: 어리석은 / 지금: 친절한, 좋은
  • silly → blessed옛날 뜻: 축복받은 / 지금: 바보 같은
  • awful → full of awe옛날 뜻: 경외로운 / 지금: 끔찍한
연상법 단어도 나이를 먹어요. nice는 철든 바보, silly는 철없는 천사, awful과 awesome은 같은 awe에서 갈라진 형제예요.

지금은 이렇게 써요

옛날 뜻은 잊어도 돼요. 대신 지금 쓰는 뉘앙스는 꼭 알아 두면 좋아요.

  • That's so nice of you.정말 친절하시네요. (고마울 때)
  • Don't be silly.무슨 소리야, 별말을 다 해. (상대가 미안해하거나 겸손할 때)
  • I feel awful about it.그거 정말 미안해. / 마음이 너무 안 좋아.
  • That's awesome!대박이다! 끝내준다!
  • Thanks, guys!다들 고마워! (남녀 섞인 모임에도 써요)

자주 하는 실수

  • 친구가 "도와줘서 고마워, 귀찮게 해서 미안해"라고 할 때You're silly.Don't be silly!무슨 소리야, 별거 아니야!왜?You're silly는 '너 참 엉뚱하다'처럼 사람을 평가하는 말이 돼요. Don't be silly는 '별말을 다 한다, 신경 쓰지 마'라는 따뜻한 관용 표현이에요.
  • 맛있는 음식을 먹고 감탄할 때This is awful good!This is awesome!이거 진짜 맛있다!왜?awful good(엄청 좋은)은 미국 일부 지역의 구어라 낯설게 들릴 수 있어요. awful 하나만 쓰면 '끔찍하다'예요. 칭찬은 awesome, amazing이 확실해요.

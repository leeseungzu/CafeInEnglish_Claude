뜻이 두 개예요

① How are you?에 대한 대답: I'm good. = 잘 지내
② 뭔가를 권할 때의 대답: I'm good. = 괜찮아요, 됐어요 (정중한 거절)

한국인이 자주 헷갈리는 건 ②예요. 점원이 봉투가 필요하냐고 물었는데 I'm good이라고 하면 '필요 없어요'라는 뜻이에요. 받고 싶을 땐 Yes, please.라고 해요.

연상법 '나는 이미 충분히 good한 상태라 더 필요 없어요'라고 생각해 보세요.

예문

  • Do you want some more? I'm good, thanks.더 줄까? 아니 괜찮아, 고마워.
  • Do you need a bag? I'm good.봉투 필요하세요? 괜찮아요.
  • Can I get you anything to drink? I'm good for now.마실 거 갖다 드릴까요? 지금은 괜찮아요.

비슷한 표현

  • No, thanks.괜찮아요, 고마워요.
  • I'm all set.다 됐어요. (더 필요한 거 없어요)

정답과 연상법
  1. ② 괜찮아요, 됐어요 — 뭔가를 권할 때의 I'm good은 '괜찮아요, 필요 없어요'라는 정중한 거절이에요.
    연상법 · 이미 good한 상태 → 더 필요 없음!
  2. ② Yes, please. — 받고 싶을 땐 Yes, please. 나머지는 모두 '필요 없어요'라는 뜻이에요.
    연상법 · 받을 땐 Yes, please / 거절은 I'm good
  3. ① 다 준비됐어요, 더 필요 없어요 — I'm all set = 필요한 건 다 갖췄어요, 더 필요한 거 없어요.
    연상법 · all(다) set(갖춰짐) = 끝!

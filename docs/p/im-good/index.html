뜻이 두 개예요

① How are you?에 대한 대답: I'm good. = 잘 지내
② 뭔가를 권할 때의 대답: I'm good. = 괜찮아요, 됐어요 (정중한 거절)

한국인이 자주 헷갈리는 건 ②예요. 점원이 봉투가 필요하냐고 물었는데 I'm good이라고 하면 '필요 없어요'라는 뜻이에요. 받고 싶을 땐 Yes, please.라고 해요.

연상법 '나는 이미 충분히 good한 상태라 더 필요 없어요'라고 생각해 보세요.

예문

  • Do you want some more? I'm good, thanks.더 줄까? 아니 괜찮아, 고마워.
  • Do you need a bag? I'm good.봉투 필요하세요? 괜찮아요.
  • Can I get you anything to drink? I'm good for now.마실 거 갖다 드릴까요? 지금은 괜찮아요.

비슷한 표현

  • No, thanks.괜찮아요, 고마워요.
  • I'm all set.다 됐어요. (더 필요한 거 없어요)

한눈에 정리

질문I'm good의 뜻
How are you?잘 지내
Do you need a bag?괜찮아요 (필요 없어요)
More water?괜찮아요 (됐어요)

'괜찮아요'가 두 가지 뜻이라서

한국어 '괜찮아요'는 참 편리한 말이에요. '더 드릴까요?'에 '괜찮아요'라고 하면 거절이지만, '이거 써도 괜찮아요?'에 '괜찮아요'라고 하면 허락이 되죠. 말투와 상황으로 뜻을 구분하는 거예요. 그래서 영어에서도 '괜찮아요'를 그대로 옮기려다 Okay나 Good을 고르기 쉬워요.

그런데 영어는 받을 때와 거절할 때 쓰는 말이 비교적 뚜렷하게 나뉘어요. 받을 땐 Yes, please, 거절할 땐 I'm good이나 No, thanks예요. good이라는 단어 때문에 '좋아요, 주세요'로 착각하기 쉬운데, 여기서 good은 '지금 상태가 좋으니 더 필요 없다'는 뜻이라는 걸 기억하면 헷갈리지 않아요.

실제 대화 · 디저트를 권할 때

  • Can I get you anything else? Maybe some dessert?더 필요하신 거 있으세요? 디저트는요?
  • I'm good, thanks. Could we get the check?괜찮아요, 고마워요. 계산서 주시겠어요?
  • Sure. Do you want a box for the leftovers?네. 남은 음식 포장해 드릴까요?
  • Oh, yes, please. That would be great.아, 네, 부탁해요. 그럼 좋겠어요.

같은 대화 안에서도 필요 없는 건 I'm good, 받고 싶은 건 Yes, please로 나눠서 대답하는 게 보이죠. 식당에서 쓰는 다른 문장은 해외 식당 영어에서 이어서 볼 수 있어요.

거절에도 온도가 있어요

표현느낌잘 어울리는 곳
I'm good, thanks.가볍고 친근함친구, 카페, 식당
I'm fine, thanks.담백함권유를 짧게 사양할 때
No, thank you.정중한 기본형누구에게나
I'm all set.필요한 건 다 갖췄음계산대, 식사 마무리

알아 두기 I'm good만 짧게 툭 던지면 상황에 따라 무뚝뚝하게 들릴 수 있어요. 뒤에 thanks를 붙이거나 웃으면서 말하면 훨씬 부드러워요.

I'm good, 이렇게도 이어 말해요

I'm good 뒤에 짧은 말을 붙이면 거절이 더 자연스럽고 구체적이 돼요. 무엇이 충분한지 말하고 싶을 땐 I'm good on + 명사를 쓰기도 해요.

  • I'm good on coffee, thanks. Just water, please.커피는 괜찮아요. 물만 주세요.
  • I'm good, but thanks for asking.괜찮아요, 그래도 물어봐 줘서 고마워요.
  • Are we good? Yeah, we're good.우리 괜찮은 거지? 응, 아무 문제 없어. (서운한 일이 없는지 확인할 때)

마지막 예문처럼 주어가 we가 되면 '우리 사이에 문제없다'는 뜻이 돼요. 작은 다툼이나 실수 뒤에 마음이 풀렸는지 확인할 때 자주 써요.

자주 하는 실수

  • 봉투가 필요한데I'm good.Yes, please.I'm good은 '필요 없어요'라는 거절이에요.왜?권유에 대한 I'm good은 '난 이미 괜찮으니 필요 없어'라는 뜻이에요. 그래서 봉투가 필요할 때 쓰면 정말 봉투를 안 줘요.
  • 필요 없어서 '괜찮아요' 하고 싶을 때Okay.No, thanks.Okay는 '네, 주세요'로 알아들어요. 필요 없으면 No, thanks나 I'm good이라고 해요.왜?Okay는 '좋아요, 그렇게 해요'라는 동의예요. 한국어 '괜찮아요'는 거절도 되지만 Okay는 받겠다는 뜻으로 알아듣기 쉬워요.

자주 묻는 질문

Q. How are you?에 I'm well이 맞고 I'm good은 틀린 거 아닌가요?
일상 대화에서는 I'm good이 아주 흔하고 자연스러워요. 격식을 갖춘 자리에서 I'm well을 쓰는 사람도 있지만, I'm good을 틀렸다고 보지는 않아요. 인사 대답을 더 다양하게 하고 싶다면 How are you? 대답하는 법을 참고하세요.

Q. I'm good with that은 무슨 뜻이에요?
with가 붙으면 거절이 아니라 '그거 괜찮아, 난 찬성이야'라는 뜻이에요. "Friday? I'm good with that."이라고 하면 '금요일? 난 좋아'예요. 뒤에 무엇이 오는지 함께 봐야 해요.

정답과 연상법
  1. ② 괜찮아요, 됐어요 — 뭔가를 권할 때의 I'm good은 '괜찮아요, 필요 없어요'라는 정중한 거절이에요.
    연상법 · 이미 good한 상태 → 더 필요 없음!
  2. ② Yes, please. — 받고 싶을 땐 Yes, please. 나머지는 모두 '필요 없어요'라는 뜻이에요.
    연상법 · 받을 땐 Yes, please / 거절은 I'm good
  3. ① 다 준비됐어요, 더 필요 없어요 — I'm all set = 필요한 건 다 갖췄어요, 더 필요한 거 없어요.
    연상법 · all(다) set(갖춰짐) = 끝!

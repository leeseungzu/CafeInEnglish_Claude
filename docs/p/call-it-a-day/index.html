"Let's call it a day", '오늘은 여기까지 하자'

하던 일을 마무리하는 원어민의 퇴근 신호

It's almost seven. Should we keep going?
Let's call it a day.
오늘은 여기까지 해요.

퇴근 시간이 다가올 때 회의실이나 사무실에서 정말 자주 들리는 말이 Let's call it a day.예요. 뜻은 "오늘은 여기까지 하자". 단어만 보면 "그걸 하루라고 부르자?"처럼 알쏭달쏭한데, 원어민에게는 '이만하면 됐다'며 일을 마무리하는 신호예요.

'하루'라고 치고 끝내자는 말

메리엄웹스터 사전은 call it a day를 '하던 일을 그날은, 또는 당분간 그만두다'로 풀이해요. 롱맨 사전도 '충분히 했거나 지쳐서 일을 그만하기로 하다'라고 설명하고 비격식(informal) 표현으로 표시해요.

여기서 call은 '전화하다'가 아니라 '~라고 치다, ~로 여기다'에 가까워요. "오늘 한 걸로 하루치 일을 한 셈 치자"는 그림이에요. 그래서 일이 다 끝나지 않았더라도 "이만하면 됐다"는 마음으로 쓰는 경우가 많아요. 혼자 공부하다가, 청소하다가, 운동하다가도 쓸 수 있어요.

  • Let's call it a day and go home.오늘은 여기까지 하고 집에 가자.
  • I'm exhausted. I'm going to call it a day.너무 지쳤어. 오늘은 그만할래.
  • We worked until six and then called it a day.우리는 6시까지 일하고 마무리했어요.
  • Should we call it a day?오늘은 이만할까요?

마지막 문장처럼 질문으로 바꾸면 상대 의견을 묻는 부드러운 제안이 돼요. 상사나 팀원에게 먼저 끝내자고 말하기 부담스러울 때 쓰기 좋아요.

밤이면 night, 그만두면 quits

call it 뒤에 오는 말만 바꾸면 뜻이 달라져요. 저녁 모임이나 밤늦게까지 하던 일을 끝낼 때는 call it a night, 일이나 활동을 그만둘 때는 call it quits를 많이 써요.

표현뜻이럴 때
call it a day오늘은 여기까지 하다하던 일·업무를 그날은 끝낼 때
call it a night오늘 밤은 여기까지 하다저녁 모임, 밤샘 작업을 끝내고 집에 가거나 잘 때
call it quits그만두다, 손을 떼다그만둘 때 (오래 하던 일을 접을 때 특히 자주)
  • It's getting late. Let's call it a night.늦었다. 오늘 밤은 여기까지 하자.
  • After twenty years, he decided to call it quits.20년 만에 그는 일을 그만두기로 했어요.

call it quits에는 '빚이나 다툼을 셈 끝난 걸로 치다'라는 뜻도 있어요. 롱맨 사전은 "20달러만 주면 우리 셈은 끝난 걸로 하자" 같은 예문을 들어요. 반면 call it a day는 주로 그날 하던 일을 끝낼 때 써요. 다만 옥스퍼드 학습자 사전에 '40년 정치 인생을 마무리할 때'라는 예문이 있을 만큼, 오랜 경력을 접는다는 뜻으로 쓰일 때도 있어요.

call을 '부르다'로만 알면 막혀요

한국인이 이 표현을 처음 들으면 call을 '부르다, 전화하다'로 해석해서 "하루를 부르자?" 하고 멈칫해요. 하지만 call에는 '~라고 부르다'에서 넓어진 '~라고 치다'라는 쓰임이 있어요. 숫자를 대충 맞출 때 Let's just call it ten dollars.(그냥 10달러로 치자)라고 하는 것과 같은 call이에요. 그래서 call it a day는 '오늘 한 걸로 하루를 채운 셈 치자'라는 말이 돼요. 이렇게 이해하면 night, quits로 바뀌어도 바로 감이 와요.

연상법 달력에 오늘 날짜를 동그라미 치며 "이걸로 하루(a day) 끝!" 하고 부르는(call) 모습.

자주 하는 실수

  • 회의를 마무리하며 '오늘은 여기까지 하죠'라고 할 때Let's call a day.Let's call it a day.오늘은 여기까지 하죠.왜?굳어진 표현이라 it이 꼭 들어가요. it을 빼면 원어민에게 뜻이 통하지 않는 문장이 돼요.

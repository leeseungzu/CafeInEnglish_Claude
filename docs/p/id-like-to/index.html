I want가 요구처럼 들리는 이유

I want ~는 틀린 말은 아니지만 직설적이라 창구에서는 요구하는 것처럼 들릴 수 있어요. I'd like ~(= I would like)는 '~하고 싶습니다'라는 정중한 말이에요.

I'd like + 명사 : I'd like a refund. (환불받고 싶어요)
I'd like to + 동사 : I'd like to open an account. (계좌를 만들고 싶어요)
연상법 would가 들어가면 한 발 물러선 공손함! I'd의 d는 약하게 들려서 '아잇 라익'처럼 들려요.

창구에서 바로 쓰는 문장

  • I'd like to open a bank account.계좌를 개설하고 싶어요.
  • I'd like to make an appointment.예약하고 싶어요.
  • I'd like a refund, please.환불받고 싶어요.

직원이 이렇게 물어요

Would you like ~?는 Do you want ~?의 정중한 형태예요.

  • Would you like a receipt?영수증 드릴까요?
  • Would you like to leave a message?메시지 남기시겠어요?

공손함의 3단계

원하는 걸 말하는 방법은 하나가 아니에요. 같은 부탁도 말투에 따라 온도가 달라져요. 처음 가는 곳이나 직원, 처음 만난 사람에게는 가운데 단계인 I'd like가 가장 무난해요.

단계표현느낌
직설I want a refund.환불해 주세요. (요구처럼 들릴 수 있음)
정중I'd like a refund, please.환불받고 싶습니다. (어디서나 무난)
아주 공손I was wondering if I could get a refund.혹시 환불이 가능할까 해서요. (조심스러운 부탁)

한국어로 치면 '환불해 줘요', '환불받고 싶습니다', '혹시 환불 가능할까요?'의 차이와 비슷해요. 내용은 같아도 듣는 사람이 받는 인상이 달라요.

상황별로 바로 쓰기

  • I'd like a medium latte, please.라테 미디엄으로 주세요. (카페)
  • I'd like to check in, please.체크인하려고요. (호텔)
  • I'd like to book a table for two at seven.7시에 두 명 자리 예약하고 싶어요. (식당 전화)
  • I'd like to speak to the manager, please.매니저와 이야기하고 싶어요. (문제가 생겼을 때)

실제 대화 · 은행 창구에서

  • Hi, how can I help you today?안녕하세요, 무엇을 도와드릴까요?
  • Hi, I'd like to open a savings account.안녕하세요, 예금 계좌를 하나 만들고 싶어요.
  • Sure. Would you like to set up online banking too?네. 인터넷 뱅킹도 같이 신청하시겠어요?
  • Yes, I'd like that.네, 그렇게 해 주세요.

알아 두기 미국 카페에서는 Can I get a latte?도 아주 흔하게 들려요. 짧고 친근한 주문 방식이라 무례하지 않아요. 다만 어디서든 실수 없이 쓰려면 I'd like가 가장 안전해요. 대답할 때 I'd like that.(그거 좋겠네요)처럼 짧게 받아도 자연스러워요.

왜 한국인은 I want를 먼저 떠올릴까?

학교에서 '원하다 = want'로 단어를 먼저 외웠기 때문이에요. 한국어 '원해요'는 존댓말 어미만 붙이면 충분히 공손해지지만, 영어는 어미 대신 단어 선택과 문장 구조로 공손함을 표현해요. 그래서 want에 please를 붙여도 'I want a refund, please.'는 여전히 조금 단호하게 들려요.

영어에서 공손함을 만드는 대표적인 방법은 과거형이나 가정형을 빌려 한 발 물러서는 것이에요. would, could, was wondering처럼 '혹시 ~라면'의 거리를 두면 상대에게 거절할 여지를 주는 느낌이 생기고, 그게 곧 배려로 받아들여져요. I'd like의 would가 바로 그 역할을 해요.

발음 한 걸음 더

I'd like to는 실제로 빠르게 말하면 '아잇 라익 투'보다 '아이 라익트'에 가깝게 들려요. d는 거의 들리지 않고, like와 to가 붙어서 한 덩어리가 돼요. 그래서 듣기 연습을 할 때 'I like to'와 구분하기 어렵다면, 앞뒤 상황을 보세요. 창구나 주문처럼 '지금 원하는 것'을 말하는 자리라면 거의 항상 I'd like to예요.

자주 하는 실수

  • I'd like open an account.I'd like to open an account.동사 앞에는 to가 꼭 필요해요.왜?I'd like는 I would like예요. 뒤에 명사가 오면 to 없이(I'd like a coffee), 동사가 오면 to가 다리 역할을 해요(I'd like to open).
  • I like to make an appointment.I'd like to make an appointment.I like to는 '평소에 ~하는 걸 좋아해요'라는 다른 뜻이에요.왜?I'd(I would) like to는 '지금 ~하고 싶어요'라는 바람이고, I like to는 '평소에 ~하는 걸 좋아해요'라는 취향이에요. d 하나로 뜻이 바뀌어요.

자주 묻는 질문

Q. I want는 아예 쓰면 안 되나요?
아니에요. 친구나 가족 사이(I want pizza tonight!)나, 꿈과 의지를 말할 때(I want to be a teacher.)는 I want가 더 자연스러워요. 정중함이 필요한 건 '상대에게 무언가를 부탁하는 순간'이에요.

Q. I'd like to와 I'd love to는 뭐가 달라요?
I'd love to는 주로 제안에 대한 대답이에요. "Do you want to join us?"(같이 갈래?)에 "I'd love to!"(정말 좋아요!)라고 하면 기쁜 마음까지 전해져요. 내가 먼저 무언가를 요청할 때는 I'd like to가 더 잘 어울려요.

정답과 연상법
  1. ③ I'd like to open an account. — I'd like to ~ = ~하고 싶습니다. 창구에서 첫마디로 가장 무난해요.
    연상법 · would(I'd) = 한 발 물러선 공손함!
  2. ② I would — 동사원형 like 앞의 I'd는 I would예요. (I'd 뒤에 과거분사가 오면 I had예요: I'd finished.)
    연상법 · would like = 정중한 want
  3. ② 영수증 드릴까요? — Would you like ~? = ~하시겠어요?, ~드릴까요? 받고 싶으면 Yes, please. 필요 없으면 No, thanks.
    연상법 · Would you like = Do you want의 공손 버전!

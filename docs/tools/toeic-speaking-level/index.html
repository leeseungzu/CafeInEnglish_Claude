자주 묻는 질문

토익스피킹 만점은 몇 점인가요?

200점이에요. 200점이면 가장 높은 등급인 Advanced High(AH)예요.

IM1, IM2, IM3는 몇 점인가요?

공식 안내에서는 Intermediate Mid를 110~130점으로 묶고 Mid1 < Mid2 < Mid3로 나눠요. 채용 공고에서는 흔히 IM1을 110점, IM2를 120점, IM3를 130점으로 봐요.

성적은 언제 나오나요?

공식 안내 기준으로 응시일로부터 약 5일 뒤 낮 12시에 발표돼요.

시험은 몇 문항, 몇 분인가요?

11문항이고 약 20분 동안 봐요. 문장 읽기, 사진 묘사, 질문에 답하기, 정보 보고 답하기, 의견 말하기로 나뉘어요.

토익스피킹 등급과 오픽 등급은 같은가요?

둘 다 ACTFL 등급 이름을 쓰지만 시험 방식이 달라서 똑같다고 볼 수는 없어요. 두 시험을 공식으로 바꿔 주는 환산표도 없어요. 비교가 필요하면 영어 시험 점수 비교표를 참고하세요.

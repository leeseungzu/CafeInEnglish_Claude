Safari에서 열어 주세요

인스타·스레드 같은 앱 안에서는 홈 화면에 추가할 수 없어요. 딱 한 번만 Safari로 열면 돼요.

  1. 1화면의 ··· 버튼을 눌러요
  2. 2외부 브라우저에서 열기를 눌러요
  3. 3Safari에서 이 페이지가 다시 열리면 안내대로 추가해요

메뉴가 안 보이면 주소를 복사해 Safari 주소창에 붙여 넣어 주세요.

크롬에서 열어 주세요

앱 안의 브라우저에서는 설치가 안 돼요. 버튼을 누르면 크롬으로 열려요.

크롬으로 열기

안 열리면 오른쪽 위 ⋮ 메뉴에서 '다른 브라우저로 열기'를 눌러 주세요.

브라우저로 여는 중이에요

카카오톡 안에서는 설치가 안 돼서, 외부 브라우저로 바로 넘겨 드릴게요.

홈 화면에 추가하기

세 번만 누르면 끝나요.

  1. 1아래쪽 공유 버튼을 눌러요 (안 보이면 ··· 버튼 안에 있어요)
  2. 2목록을 올려 홈 화면에 추가를 눌러요
  3. 3오른쪽 위 추가를 누르면 끝!

아이폰은 Safari와 홈 화면 앱이 기록을 따로 저장해요. 오답노트·필사는 앱에서 시작하는 걸 추천해요.

앱 설치하기

버튼 한 번이면 홈 화면에 카페인영어가 생겨요.

  1. 1오른쪽 위 ⋮ 메뉴를 눌러요
  2. 2홈 화면에 추가 또는 앱 설치를 눌러요

휴대폰으로 설치하기

휴대폰 카메라로 QR을 비추면 이 페이지가 열려요. 안내대로 홈 화면에 추가하면 끝이에요.

휴대폰별 설치 방법

쓰는 휴대폰을 골라 보세요.

Safari에서

  1. 1Safari로 cafeinenglish.com/app 을 열어요
  2. 2아래쪽 공유 버튼을 눌러요 (안 보이면 ··· 버튼 안)
  3. 3 홈 화면에 추가 → 오른쪽 위 추가

인스타·카톡 안에서 열었다면 먼저 Safari로 열어 주세요.

크롬에서

  1. 1크롬으로 cafeinenglish.com/app 을 열어요
  2. 2카페인영어 앱 설치 버튼을 눌러요. 버튼이 없으면 오른쪽 위 ⋮ 메뉴를 눌러요
  3. 3홈 화면에 추가 또는 앱 설치 → 설치

삼성 인터넷에서

  1. 1아래쪽 ≡ 메뉴를 눌러요
  2. 2현재 페이지 추가 → 홈 화면을 눌러요

인스타·카톡 안에서 열었다면 먼저 크롬이나 삼성 인터넷으로 열어 주세요.
